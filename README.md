# ☕ Научный Кофе

Telegram-бот для ежемесячных случайных встреч выпускников программы «Кадровый резерв Наука».
Работает внутри группового чата.

## Возможности

- **Опрос в чате** — бот постит poll для записи на встречу
- **Автоматические пары** — случайный мэтчинг с анти-повторами
- **Результаты в чат** — одно сообщение со списком пар
- **Ежемесячный цикл** — opt-in → мэтчинг → напоминание → фидбек
- **Админ-команды** — `/coffee`, `/match`, `/stats`

## Быстрый старт

```bash
cd science-coffee
pip3.11 install -r requirements.txt
cp .env.example .env
# Заполнить BOT_TOKEN и ADMIN_IDS
python3.11 -m bot.main
```

Затем:
1. Добавь бота в групповой чат
2. Сделай бота администратором (нужно для отправки poll)
3. Напиши `/chatid` в чате — скопируй ID в `.env` (`GROUP_CHAT_ID`)
4. Перезапусти бота

## Команды (только для админов)

| Команда | Описание |
|---------|----------|
| `/coffee` | Создать раунд + отправить poll |
| `/match` | Запустить мэтчинг + опубликовать пары |
| `/stats` | Показать статистику |
| `/chatid` | Показать ID текущего чата |

## Настройка

| Переменная | Описание | Обязательна |
|-----------|----------|:-----------:|
| `BOT_TOKEN` | Токен от @BotFather | ✅ |
| `ADMIN_IDS` | Telegram ID администраторов (через запятую) | ✅ |
| `GROUP_CHAT_ID` | ID группового чата (для автоматического цикла) | ❌ |

## Ежемесячный цикл (автоматический, если задан GROUP_CHAT_ID)

```
1-й понедельник, 10:00   →  Создание раунда + poll в чат
2-й понедельник, 18:00   →  Формирование пар + публикация в чат
~18-е число, 10:00       →  Напоминание в чат
~30-е число, 10:00       →  Фидбек-poll + завершение раунда
```

## Стек
